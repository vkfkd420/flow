# flow - 파일 확장자 차단 & 업로드

파일 업로드 시 확장자 기반 차단 정책을 관리하고, 실제 업로드에 정책을 적용하는 과제 프로젝트입니다.

## 기술 스택

| 구분 | 스택 |
|------|------|
| Frontend | Vue 2.7 (Vue CLI 5) |
| Backend | Spring Boot 4.0.8, Java 17, Maven, MyBatis |
| DB | MySQL, DBeaver |

## 폴더 구조

```
flow/
├─ frontend/         Vue 2
├─ backend/          Spring Boot
├─ db/
│  ├─ schema.sql     테이블 정의
│  └─ seed.sql       초기 데이터
├─ README.md
├─ CONSIDERATIONS.md 고려사항 문서
└─ PROMPT_LOG.md     AI 활용 기록
```
